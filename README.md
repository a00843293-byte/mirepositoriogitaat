
# Buscador de archivos

Este proyecto permite buscar la palabra "home" dentro de los archivos de una carpeta y mostrar las rutas de los archivos donde aparece.

## Integrantes

- Integrante 1: Funcion listar_archivos()
- Integrante 2: Funcion buscar_palabra()
- Integrante 3: Programa principal e integracion

## Requisitos

Tener Python 3 instalado.

## Instrucciones de ejecucion

1. Descargar el repositorio de GitHub.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar el siguiente comando:

python3 main.py

4. Escribir la ruta de la carpeta donde se desea buscar.
5. El programa mostrara las rutas de los archivos que contienen "home".

## Funcionamiento

El programa utiliza listar_archivos(carpeta) para obtener los archivos y buscar_palabra(archivos, "home") para encontrar coincidencias.

Si no encuentra coincidencias, muestra un mensaje al usuario.
